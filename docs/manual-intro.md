# วิธีใช้คู่มือเล่มนี้

**PD Monitor** คือระบบที่โรงงานใช้แทนการจดงานผลิตลงกระดาษ — ทุกฝ่าย (วางแผน · ผลิต · QC · QA · คลัง · วิศวกรรม · บัญชีต้นทุน · ผู้บริหาร) เห็นสถานะงานชุดเดียวกัน บันทึกที่เดียวกัน และย้อนดูได้ว่าใครทำอะไรเมื่อไร

คู่มือเล่มนี้รวม 2 เล่มเดิมเข้าด้วยกัน แบ่งเป็น 2 ภาคที่ใช้คนละแบบ

| | 📕 ภาค 1 — ฝึกปฏิบัติ | 📗 ภาค 2 — คู่มืออ้างอิง |
|---|---|---|
| ใช้ตอนไหน | **ครั้งแรกที่ใช้ระบบ** | เมื่อสงสัยเรื่องใดเรื่องหนึ่ง |
| อ่านยังไง | อ่านเรียงจากต้นจนจบ **พร้อมลงมือทำตามไปด้วย** | เปิดจากสารบัญเฉพาะหัวข้อที่ต้องการ |
| เนื้อหา | เดินงานจริง 1 ล็อต ตั้งแต่เปิดงานจนปิดงาน บอกทุกปุ่มที่ต้องกด | รายละเอียดทุกหน้าจอ · ทุกสิทธิ์ · ทุกกติกา |
| ใช้เวลา | ประมาณ 1–2 ชั่วโมง | เปิดหาแป๊บเดียว |

> 💡 **ถ้าเพิ่งเริ่มใช้ระบบ** — อ่านภาค 1 ให้จบก่อน แล้วเก็บภาค 2 ไว้เปิดตอนทำงานจริง

---

## ฉันเป็นฝ่ายไหน — ต้องอ่านตรงไหน

หาแถวของตัวเองในตารางนี้ แล้วเปิดไปตามหัวข้อที่ระบุ (เลขหน้าดูได้จากสารบัญ)

| ฝ่ายของคุณ | ภาค 1 อ่านขั้นไหน | ภาค 2 เปิดหัวข้อไหน |
|---|---|---|
| **วางแผน (PLN)** | Part B ทั้งหมด · C1 ยืนยันแผนผลิต | บอร์ดงาน · สร้างงานใหม่ · ปริ้นใบแจ้งผลิต · ปริ้นตารางบอร์ดงาน |
| **ผลิต (PROD)** | C2–C7 (เบิกของ → เคลียร์ไลน์ → ผลิต → บันทึกผล) · C10 ส่งตรวจ QC | หน้ารายละเอียดงาน · บันทึกผลผลิตรายวัน · Line Clearance |
| **หัวหน้าฝ่ายผลิต** | C5 ยืนยัน Line Clearance · C8 อนุมัติบันทึกผลผลิต | กติกา 2 ลายเซ็น · คำขอแก้ไขย้อนหลัง |
| **QC** | C9 In-process QC · C10 ลงนาม QC | ตรวจ QC / QA · In-process QC |
| **หัวหน้า QC** | C9 (ช่วงอนุมัติผลตรวจ) | กติกา 2 ลายเซ็น · คำขอแก้ไขย้อนหลัง |
| **QA** | C11 เก็บตัวอย่าง · C12 Incident Case · C13 ปล่อยผ่าน | Incident Case · ไล่ย้อนล็อต · ประวัติ / Audit |
| **คลังสินค้า (WH)** | C2 กดสถานะพร้อม · C14 รับ FG เข้าคลัง | เบิกวัตถุดิบ/บรรจุภัณฑ์ · คลัง / FG · ผลิตภัณฑ์คลัง |
| **วิศวกรรม (ENG)** | A4 เครื่องจักร | เครื่องจักร |
| **บัญชีต้นทุน (COST)** | D7 แดชบอร์ด | แดชบอร์ด (บล็อกต้นทุนค่าแรง) |
| **ผู้บริหาร (MGR)** | อ่านทั้งเล่มแบบผ่าน ๆ | สรุปรายฝ่าย · แดชบอร์ด · ประวัติ / Audit |
| **ผู้ดูแลระบบ (Admin)** | Part A ทั้งหมด | จัดการผู้ใช้ · บริษัท / เลขงาน |

## สัญลักษณ์ที่ใช้ในเล่มนี้

ภาค 1 ใช้สัญลักษณ์นำบรรทัดบอกว่า "ให้ทำอะไร"

| สัญลักษณ์ | ความหมาย |
|:---:|---|
| 📍 | **ไปที่ไหน** — เส้นทางเมนู เช่น `เมนูซ้าย → บอร์ดงาน` |
| 🔑 | **ใช้บัญชีของฝ่ายไหน** ทำขั้นนี้ |
| ✍️ | **กรอกอะไร** ลงในช่อง |
| 🖱️ | **กดปุ่มไหน** |
| ✅ | **ผลที่ควรเห็น** ถ้าทำถูก |

ส่วนกล่องข้อความสีเขียวมี 4 แบบ

> ⚠️ **ข้อควรระวัง** — ถ้าพลาดตรงนี้จะทำต่อไม่ได้ หรือต้องแก้ย้อนหลัง

> 💡 **เคล็ดลับ** — ทางลัดหรือของที่หลายคนไม่รู้ว่ามี

> 🔒 **กติกา GMP** — ข้อบังคับตามมาตรฐาน ระบบจะไม่ยอมให้ข้าม

> 🔑 **เรื่องสิทธิ์** — ใครทำได้ ใครทำไม่ได้

## ก่อนเริ่ม ต้องมีอะไรบ้าง

1. **บัญชีของตัวเอง** — หัวหน้าแผนกหรือผู้ดูแลระบบเป็นคนเปิดให้ (ดูภาค 1 Part A) · เข้าครั้งแรกระบบจะบังคับตั้งรหัสผ่านใหม่
2. **เบราว์เซอร์** — Chrome, Edge หรือ Safari รุ่นใหม่ · ใช้บนคอมพิวเตอร์ แท็บเล็ต หรือมือถือก็ได้
3. **ที่อยู่เว็บ** — `https://pd-monitor.vercel.app` (เพิ่มลงหน้าจอมือถือได้เหมือนแอป)

> 🔑 **คุณจะเห็นเมนูไม่เท่ากับเพื่อน** — ระบบซ่อนเมนูที่ฝ่ายคุณไม่ได้ใช้ ไม่ใช่ความผิดพลาด
> ถ้าคิดว่าควรเห็นแต่ไม่เห็น ให้แจ้งหัวหน้าแผนกตรวจสิทธิ์ให้

> ⚠️ **คู่มือเล่มนี้ตรงกับระบบ ณ วันที่ปรับปรุงบนปก** — ระบบมีการพัฒนาต่อเนื่อง
> ถ้าหน้าจอจริงต่างจากรูปในคู่มือเล็กน้อย ให้ยึดหน้าจอจริงเป็นหลัก
