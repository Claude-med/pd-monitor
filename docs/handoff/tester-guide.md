# 2. สถานการณ์ทดสอบหลัก — เดินงาน 1 ล็อต ครบทุกฝ่าย

ทดสอบร่วมกันทั้งทีม: ฝ่ายวางแผนเปิดงาน 1 งาน แล้วส่งต่อกันไปจนเข้าคลัง · **ทุกขั้นที่ต้องอนุมัติ ผู้อนุมัติต้องเป็นคนละคนกับผู้บันทึก** (กฎ 2 ลายเซ็น)

| ขั้น | ใครทำ (บัญชี) | ทำอะไร | ดูตรงไหน |
|---|---|---|---|
| 1 | ฝ่ายวางแผน | สร้างงานใหม่ (เลือกบริษัท · ลูกค้า · ผลิตภัณฑ์ · จำนวน) | บอร์ดงาน → *＋ สร้างงานใหม่* |
| 2 | ฝ่ายวางแผน | ใส่วันที่แผน แล้วกด **ยืนยันแผนผลิต** | หน้างาน |
| 3 | ฝ่ายผลิต | ขอเบิกวัตถุดิบ/บรรจุภัณฑ์ของงาน | หน้างาน → ส่วนเบิกของ |
| 4 | คลังสินค้า | เปลี่ยนสถานะรายการเบิกเป็น **พร้อม** | เมนู *เบิกวัตถุดิบ / บรรจุภัณฑ์* |
| 5 | ฝ่ายผลิต | กด **เริ่มผลิต** · ใส่เลขล็อต | หน้างาน |
| 6 | ฝ่ายผลิต → **หัวหน้าฝ่ายผลิต** | บันทึก Line Clearance → หัวหน้ายืนยัน | หน้างาน · เมนู *⏳ รออนุมัติ* |
| 7 | ฝ่ายผลิต → **หัวหน้าฝ่ายผลิต** | บันทึกผลผลิต → หัวหน้าอนุมัติ | หน้างาน · *รออนุมัติ* |
| 8 | QC → **หัวหน้า QC** | บันทึกผลตรวจระหว่างผลิต (in-process) → หัวหน้าอนุมัติ | หน้างาน · เมนู *ตรวจ QC / QA* |
| 9 | QA → **หัวหน้า QA** | บันทึกการเก็บตัวอย่าง → หัวหน้าอนุมัติ | หน้างาน · *ตรวจ QC / QA* |
| 10 | **หัวหน้าฝ่ายผลิต** | กด **ส่งตรวจ QC** (ระบบเช็กว่าบันทึกครบก่อน) | หน้างาน |
| 11 | **หัวหน้า QC** | **QC ผ่าน → ส่ง QA** (ใส่รหัสผ่านเพื่อลงนาม) | หน้างาน |
| 12 | **หัวหน้า QA** | **QA ปล่อยผ่าน → FG** (ใส่รหัสผ่านเพื่อลงนาม) | หน้างาน |
| 13 | คลังสินค้า | รับเข้าคลัง FG (ใส่จำนวนที่รับ) | เมนู *คลัง / FG* |
| 14 | QA / ผู้บริหาร | เปิด **eBR** (บันทึกการผลิตทั้งล็อต) แล้วลองปริ้น | หน้างาน → *eBR* |

> 💡 ถ้ากดปุ่มไม่ได้ หรือระบบขึ้นว่า "ยังขาด…" — ส่วนใหญ่คือ **ด่าน GMP ที่ตั้งใจไว้** (เช่น ยังไม่อนุมัติ ยังเบิกของไม่ครบ)
> ให้ทำตามที่ระบบบอก · ถ้าข้อความอ่านแล้วไม่เข้าใจว่าต้องทำอะไร **ให้แจ้งมาด้วย** — นั่นคือสิ่งที่ต้องปรับ

**ลองกรณีผิดปกติด้วย** (สำคัญพอ ๆ กับกรณีปกติ)
- QC หรือ QA **ตีกลับ** งาน → งานต้องกลับไป *กำลังผลิต* แล้วเดินใหม่ได้
- บันทึกผลตรวจ in-process เป็น **ไม่ผ่าน** → หัวหน้า QC พิจารณาแล้วต้องเปิด **Incident** อัตโนมัติ
- ขอ **แก้ไขบันทึก** ที่อนุมัติแล้ว → หัวหน้าฝ่ายอนุมัติ/ปฏิเสธคำขอ
- **ยกเลิกงาน**: หัวหน้าฝ่ายยกเลิกได้เฉพาะงานที่ยังไม่เริ่มผลิต · ผู้บริหารยกเลิกได้ทุกสถานะยกเว้น FG และ **คืนงาน** ได้
- ลองกดสิ่งที่ **ไม่ใช่หน้าที่ของฝ่ายตัวเอง** → ต้องไม่เห็นปุ่ม หรือระบบไม่ยอม

| บัญชีต้นทุน | ดูต้นทุนค่าแรงของงาน |
| ผู้บริหาร | แดชบอร์ด · *ประวัติ / Audit* · จัดการผู้ใช้ · ยกเลิก/คืนงาน |
