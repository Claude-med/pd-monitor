# 3. ต้องสมัคร Vercel ไหม

**ตอบตรง ๆ:** ถ้าดูแค่ "ปริมาณการใช้งาน" — **ไม่ต้อง** ใช้ 30 คนไม่ถึงเพดานฟรีแน่นอน
แต่ปัญหาอยู่ที่ **เงื่อนไขการใช้งาน** ไม่ใช่ปริมาณ

> 📌 **เงื่อนไขของ Vercel (แปลจากหน้าเว็บทางการ):** แพ็กเกจฟรีจำกัดไว้สำหรับ "การใช้ส่วนตัวที่ไม่ใช่เชิงพาณิชย์เท่านั้น"
> และนิยามเชิงพาณิชย์ว่า "ระบบที่ใช้เพื่อประโยชน์ทางการเงินของ **ใครก็ตาม** ที่เกี่ยวข้องกับการทำระบบ
> **รวมถึงพนักงานที่ได้รับเงินเดือนเป็นคนเขียนโค้ด**"

ระบบนี้ทำโดยพนักงานของบริษัท เพื่อใช้ในงานของบริษัท → **ตามนิยามนี้ถือเป็นเชิงพาณิชย์** · ถ้า Vercel ตรวจพบ อาจระงับเว็บได้

| ทาง | ค่าใช้จ่าย | งานที่ต้องทำ | ความเสี่ยง |
|---|---|---|---|
| **A. สมัคร Vercel Pro** | ≈&nbsp;700&nbsp;บาท/เดือน | กดสมัครอย่างเดียว ไม่ต้องแก้ระบบ | ไม่มี |
| **B. ถาม Vercel Support ก่อน** | 0 บาท ถ้าได้รับอนุญาต | ส่งคำถาม รอคำตอบเป็นลายลักษณ์อักษร | ถ้าไม่อนุญาต กลับไปทาง A |
| **C. ย้ายไปผู้ให้บริการที่ฟรีแล้วใช้ในบริษัทได้** (เช่น Netlify · Cloudflare) | 0 บาท | ย้ายระบบ + ทดสอบใหม่ทั้งระบบ · ต้องวัดความเร็ว | ระบบช้าลง/มีจุดพังใหม่ช่วงย้าย |

**ข้อแนะนำ: ทาง A** — เดือนละ ≈&nbsp;700&nbsp;บาท แลกกับไม่ต้องเสี่ยงเว็บถูกระงับกลางสายการผลิต และไม่ต้องย้ายระบบที่ทดสอบผ่านแล้ว ·
ถ้าต้องการประหยัด ทำ **ทาง B** ก่อน · ทาง C คุ้มเฉพาะถ้าต้องการค่าใช้จ่ายเป็นศูนย์จริง ๆ
